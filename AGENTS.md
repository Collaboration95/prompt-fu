# Prompt Fu working instructions

- This is the standalone public Prompt Fu repository. Keep changes inside this checkout unless the user authorizes otherwise.
- Use the authenticated `gh` CLI for all GitHub access.
- Keep credentials, local deployment state, private research and judge remarks out of commits.
- Do not edit, rebuild or redeploy any frozen Sites shell, or stop an existing game or tunnel process. Repository publication is not a deployment.
- Use an ephemeral port for checks. Run `npm run check`, `npm test`, and `npm run test:browser` for game or controller changes.
- Phone checks use touch input at 390 × 844 and 844 × 390. Distinguish browser emulation, synthetic AI fallbacks, physical-device checks and public endpoint checks.
- Keep one integration owner and one worker per file area. Builders run their own checks; do not start review agents or review loops.
- Report material failures, fixes and evidence limits. Surface screenshots promptly.
