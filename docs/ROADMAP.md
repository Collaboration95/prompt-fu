# Next steps

The initial public version preserves the working game and establishes repeatable checks. These are proposed follow-up changes, not completed features.

1. **Reliable phone sessions.** Prove one host plus two physical phones, including reconnects, slot assignment, neutral input after disconnect, and portrait/landscape controls.
2. **Portable generation.** Configure model names and supported CLI options, expose a deliberate fallback-only mode, and explain generation failures without leaking CLI diagnostics.
3. **Public-hosting controls.** Add host ownership and room membership, per-client usage limits, WebSocket resource bounds, and adversarial input tests.
4. **Independent hosting.** Package a backend deployment with health checks and explicit configuration so the demo does not depend on a personal computer.
5. **Offline assets and presentation.** Bundle the QR dependency, add a short gameplay clip, and choose a license before describing the project as open source.

The original improvement board is retained as [IMPROVEMENTS.html](IMPROVEMENTS.html). It is a historical ideas list, not an implementation or acceptance record.
