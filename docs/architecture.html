The host runs the fight

Phones send the moves. Codex makes the recipes.

ChatGPT Site

A thin shell opens the backend-served host game in an iframe.

Host browser

The host owns the Canvas arena, movement, hits, bots and scoring. Every gameplay frame runs here.

Phones

Joystick, throw and dash input travels through the Node relay about 20 times per second. The host sends fighter details, wins and feedback back to the phones.

Node backend

One process serves the game, relays room messages, and handles generation routes. It validates JSON recipes and supplies deterministic fallbacks.

Codex CLI

Optional read-only generation turns prompts into fighter, arena and award JSON. AI stays outside the gameplay loop.
